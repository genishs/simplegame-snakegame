## 동작 정의

### #22 백그라운드 복귀
- `frame()`은 한 프레임에서 진행시키는 시간을 0~250ms로 제한한다. 페이지가 가려진 동안 멈춰 있던 rAF가 돌아와도 밀린 시간을 재생하지 않는다(250ms ≈ 1~2틱이라 느린 프레임은 그대로 따라잡는다).
- `visibilitychange`로 페이지가 가려지면 `suspendGame()`:
  - PLAYING → 일시정지
  - COUNTDOWN → 일시정지(카운트다운은 실제 시간 기준이라, 두면 돌아오는 순간 바로 플레이가 시작된다)
  - STAGE_CLEAR → 다음 스테이지로 넘긴 뒤 일시정지(800ms 대기가 끝나 자동 시작되는 것 방지)
  - 그 밖의 상태는 그대로
- 안드로이드: `onPause`에서 `window.SnakeHost.onPause()`(= `suspendGame()`)를 부르고 `webView.onPause()`, `onResume`에서 `webView.onResume()`. WebView가 `visibilitychange`를 내는지는 WebView 버전에 따라 달라 셸이 직접 부른다.

### #23 가로 화면·컷아웃
- 보드 한 변 = min(85vw, 상한 560px(768~1023px 폭은 480px), 뷰포트 높이 − 보드 위아래 요소 높이). 페이지가 스크롤되지 않는다. 세로 화면도 같은 방식(조작 버튼 줄 포함).
- 높이 520px 이하 가로 화면: 여백·제목 크기를 줄여 보드를 크게 유지.
- 터치 기기 가로 화면: 회전 버튼을 화면 아래 양쪽 모서리, 시작/일시정지 버튼을 오른쪽 위에 띄운다. 보드는 양옆 버튼 영역을 비켜 가운데.
- 안드로이드: 폰은 세로 고정(`screenOrientation="portrait"`). Android 16에서 600dp 이상 화면은 고정을 무시하므로 위 가로 레이아웃이 받친다.
- 안드로이드: WebView를 FrameLayout으로 감싸 `displayCutout` 인셋을 padding으로 적용하고 인셋을 소비한다(WebView가 safe-area를 또 적용하지 않게). 여백 색은 페이지 배경색.

### #24 재생성 방지
- `configChanges`에 `smallestScreenSize|density`(+ 물리 키보드 연결 `keyboard|navigation`) 추가. 페이지는 자체 `resize` 이벤트로 캔버스를 다시 맞춘다.

### #25 터치 안내
- `(pointer: coarse)`이면 시작·일시정지·게임오버·막힘 안내와 카운트다운 건너뛰기 문구를 터치 표현으로 보여 준다(예: "화면을 탭해서 시작", "탭해서 계속하기", "회전 버튼으로 방향을 바꿔주세요", "화면을 탭하면 바로 시작").
- 터치 기기에서는 키보드 단축키 줄과 도움말의 키 목록을 숨기고, 도움말에 터치 조작 목록을 보여 준다.

### #26 버전
- `GAME_VERSION`(game.js)이 유일한 원천. 페이지 버전 표시는 여기서 채운다. `VERSION` 파일과 `index.html` 하드코딩 버전은 없앤다.
- `versionCode = (major*10000 + minor*100 + patch) * 100 + androidRev`. `androidRev`는 `android/gradle.properties`(기본 1, 1~99). 0.6.2 rev1 → **60201**. minor·patch가 99를 넘거나 `androidRev`가 범위를 벗어나면 빌드 실패.

### #27 R8
- release에 `isMinifyEnabled`·`isShrinkResources` = true. `@JavascriptInterface` 메서드와 어노테이션, 브릿지 클래스 public 멤버를 keep.

### #28 셸 정비
- 뒤로가기: 셸은 `window.SnakeHost.onBack()`만 부른다. PLAYING·COUNTDOWN → 일시정지, HELP → 도움말 닫기, 둘 다 `"handled"`. 그 밖엔 `"exit"`이고 셸은 앱을 백그라운드로 보낸다(`"handled"` 이외의 결과는 모두 exit 취급).
- `Android.vibrate(ms)`는 200ms 상한, 진동기가 없으면 무시.
- 화면 켜짐: 상시 `FLAG_KEEP_SCREEN_ON`을 없애고, 페이지가 PLAYING·COUNTDOWN·STAGE_CLEAR일 때만 `Android.setKeepScreenOn(true)`(상태가 바뀔 때만 호출, 플래그는 UI 스레드에서).
- `allowFileAccess`·`allowContentAccess` = false, 번들 페이지 밖으로의 이동 차단, `onDestroy`에서 WebView 해제.
- 브릿지 클래스 이름 `HostBridge`(JS 이름 `Android`는 그대로).

### #29 앱 이름
- `app_name` = "심플 스네이크".

### #32 스테이지 진행
- `enterCountdown()`이 불러오는 스테이지와 `stageIndex`를 맞춘다. "바로 게임 시작" → 스테이지 1 클리어 → 스테이지 2.

### #34 도움말 복귀 상태
- 오버레이의 「도움말」을 닫으면 연 시점의 상태로 돌아간다(READY·CHOICE·PAUSED·OVER·BLOCKED). 스테이지 클리어 대기 중에 열면 `suspendGame()`처럼 다음 스테이지로 넘긴 뒤 일시정지로 돌아온다(도움말이 떠 있는 사이 800ms 대기가 끝나 닫자마자 플레이가 시작되는 것 방지). 첫 방문 자동 도움말은 그대로 READY로 돌아간다.
