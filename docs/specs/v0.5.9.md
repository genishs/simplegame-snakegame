# v0.5.9 Spec

## Goal

소화(digestion) 모션을 **절제**하고, 뱀 머리에 **잔잔한 ambient 생동감**을 더한다. 구체적으로 (1) 사과를 먹은 뒤 몸통 속 덩어리(bulge)의 wiggle 진폭·주파수를 눈에 띄게 낮춰 "조잡하게 흔들리는" 인상을 줄이되 생동감은 남기고, (2) 머리에 비반복·저빈도의 ambient 2종 — 과일 섭취 직후의 짧은 tongue flick과 장시간 직진 시 1회 발생하는 yawn(머리 squash/스케일 미세 변형) — 을 추가한다. 본 버전은 **렌더/모션 폴리시** 변경이며, v0.5.8 보간 좌표계·게임 로직(충돌·점수·스테이지·타이밍)에는 일절 영향을 주지 않는다.

## User Stories

- (wiggle 절제) 플레이어로서, 사과를 먹은 뒤 몸통 덩어리가 과하게 흔들려 조잡해 보이지 않기를 원한다. 그래서 소화 모션이 차분하면서도 살아 있는 느낌으로 보인다.
- (tongue flick) 플레이어로서, 사과를 막 먹었을 때 뱀이 혀를 한 번 낼름하기를 원한다. 그래서 방금 무언가를 삼켰다는 귀여운 반응이 즉각적으로 전달된다.
- (yawn) 플레이어로서, 뱀이 한참 같은 방향으로 직진할 때 가끔 하품하듯 머리가 살짝 늘어났다 돌아오기를 원한다. 그래서 단조로운 직진 구간에서도 뱀이 살아 있는 듯한 잔잔한 생동감을 느낀다.
- (절제·저빈도) 플레이어로서, 위 머리 효과가 자주 반복되거나 과장되어 거슬리지 않기를 원한다. 그래서 ambient 모션이 배경처럼 은은하게 존재하되 플레이를 방해하지 않는다.

## Acceptance Criteria

### Set A — bulge wiggle 절제 (다운튜닝)

- [ ] wiggle은 **완전 제거가 아니라 감쇠**다. `TOKEN.wiggleAmpFactor`(현 `0.15`, game.js:94)를 designer 합의 목표치로 낮춘다(권장 기본 `0.06`–`0.08`, Open Questions·Decisions 참조). 0으로 두지 않는다(생동감 잔존).
- [ ] `TOKEN.wiggleFreqHz`(현 `2.0`, game.js:95)는 기본 유지하되, designer가 "너무 빠르게 떨린다"고 판단하면 하향(예: `1.2`–`2.0`) 허용. 변경 시 최종값을 HISTORY.md에 기재한다.
- [ ] `TOKEN.wigglePhaseStep`(현 `Math.PI / 3`, game.js:96)은 복수 덩어리 간 동기화 방지 목적이므로 유지한다(절제 대상 아님).
- [ ] (선택, designer 합의 시) wiggle 진폭을 덩어리 **진행 위상에 따라 감쇠**시킨다 — 덩어리가 꼬리에 가까워질수록(progressFrac → 1) 진폭이 줄어들도록 한다. 구현 시 `drawBulges`(game.js:512–558)의 `wiggleAmp` 산출부(현 game.js:542, `cellSize * TOKEN.wiggleAmpFactor * (s / TOKEN.bulgeMaxScale)`)에 진행 기반 감쇠 계수를 곱한다. 이 항목은 designer 판단에 따라 채택/미채택하며, 채택 여부를 Decisions에 기록한다.
- [ ] 변경 후에도 wiggle 진폭은 인접 셀을 침범하지 않는다(절제 방향이므로 기존 상한 `cellSize * 0.2` 이내가 자동 충족된다).
- [ ] 변경 후에도 복수 사과 연속 섭취 시 각 덩어리가 phase 오프셋으로 독립적으로 wiggle한다(동기화되어 한 덩어리처럼 보이지 않는다).
- [ ] wiggle 절제는 **토큰 값 조정만**으로 이루어지며(필요 시 진행-감쇠 계수 1줄 추가), `drawBulges`의 구조·normal 벡터 산출·bulge 형상/스케일/페이드 로직은 변경하지 않는다.

### Set B — tongue flick (과일 섭취 직후)

- [ ] 사과를 먹은 시점에 tongue flick 트리거 타임스탬프를 기록한다. 기존 `eatStart`(game.js:161, tick() 섭취 분기 game.js:403에서 `performance.now()` 설정)를 **재사용**하거나, 머리 모션 전용 타임스탬프(예: `tongueFlickAt`)를 새로 둔다. 새 변수 도입 시 `init()`(game.js:174–)에서 비활성값(`-Infinity`)으로 리셋한다.
- [ ] flick은 섭취 직후 **단 1회, 짧게** 재생된다(비반복). 지속시간은 designer 협의값(권장 `120`–`220ms`).
- [ ] 머리에는 이미 주기적 idle tongue가 존재한다(`drawSnakeHead` game.js:744–750: `now % TOKEN.headTonguePeriod < TOKEN.headTongueOn`, 토큰 `headTongueColor/Length/Period/On` game.js:78–82). flick은 이 idle tongue를 **재사용/확장**한다 — 신규 색·신규 폰트 없이 기존 `headTongue*` 토큰으로 그린다. flick 동안에는 idle 주기와 무관하게 혀가 보이도록 게이팅을 OR 결합한다(예: `idleTongueVisible || flickActive(now)`).
- [ ] (권장) flick은 단순 on/off보다 살짝 더 길게/도드라지게 보이도록 idle 대비 차별화한다(예: flick 중 혀 길이를 `headTongueLength` 기준 소폭 확대, 또는 짧은 in-out). 차별화 방식·강도는 designer 결정. 신규 색 도입은 금지.
- [ ] flick은 PLAYING 상태에서만 트리거된다(섭취가 PLAYING에서만 발생하므로 자동 충족). PAUSED 등 정지 상태로 전환되어도 진행 중인 flick이 어색하게 멈춰 보이지 않는다(짧은 지속시간으로 자연 종료).
- [ ] flick 추가가 기존 idle tongue의 주기적 동작을 망가뜨리지 않는다(섭취가 없을 때는 종전과 동일하게 동작).

### Set C — yawn (장시간 직진 시 1회)

- [ ] 현재 방향 전환 없이 직진한 시간을 추적하는 상태를 도입한다. 기존에는 직진 추적 변수가 없으므로 신규 도입한다(예: `lastTurnAt` 타임스탬프 또는 `straightTicks` 카운터). 방향 전환 지점은 `dir = nextDir` 적용 시 실제로 방향이 바뀌었는지로 판정한다(tick() game.js:390, 그리고 카운트다운 스킵 경로 game.js:953 — 둘 다 점검하여 일관되게 갱신/리셋).
- [ ] 방향이 바뀌면(좌/우 회전) 직진 추적값을 리셋한다. 직진 임계 누적은 PLAYING 중에만 진행한다.
- [ ] 연속 직진이 임계 시간(`yawnAfterMs`, 권장 기본 `4000`–`6000ms`) 이상 지속되면 yawn을 **1회** 트리거한다. yawn은 머리의 squash/스케일을 미세하게 1회 변형했다 복귀하는 비반복 모션이다.
- [ ] yawn에는 **쿨다운**을 둔다(`yawnCooldownMs`, 권장 기본 `>= 6000ms`). 쿨다운 동안에는 직진이 계속되어도 재트리거되지 않는다. 직진이 끊겼다가 다시 임계에 도달하면 쿨다운 경과 후 재트리거 가능하다.
- [ ] yawn 모션은 머리 squash 경로를 재사용한다 — `drawSnakeHead`의 `ctx.scale(pulse * sx, pulse * sy)`(game.js:719)에 yawn 변형분을 합성하거나, `computeSquash`(game.js:626–636)와 동일 패턴의 별도 yawn ease 함수를 둔다. 변형 강도는 미세(권장 facing축 `1.0`–`1.10`, perpendicular축 `1.0`–`0.95` 범위 내 1회 ease-out→ease-in)하게 한다. 정확 수치는 designer 결정.
- [ ] yawn은 eat squash(`computeSquash`)·pulse(`computePulse`)와 **시각적으로 충돌하지 않는다**. 동시 발생 가능 시 곱연산 합성이 과장되지 않도록 강도를 절제하고, designer가 동시 발생 케이스를 플레이 확인한다.
- [ ] yawn은 PLAYING 상태에서만 트리거·진행된다. PAUSED/COUNTDOWN/STAGE_CLEAR/OVER/BLOCKED 등 정지 상태에서는 직진 추적이 누적되지 않으며 yawn이 발생하지 않는다(정지 = "직진 중"이 아님).
- [ ] yawn은 **머리 위치·방향·충돌과 무관한 순수 렌더 변형**이다. 머리의 격자 위치·회전·보간(v0.5.8)에 영향을 주지 않는다.

### Set D — 신규 토큰 등록 (designer 단계 연동)

- [ ] 본 버전에서 도입되는 신규 모션 토큰을 `STYLE.md`에 등록한다. 대상: yawn 관련 토큰(`yawnAfterMs`, `yawnCooldownMs`, yawn 변형 강도/지속시간 토큰), tongue flick 지속시간/강도 토큰(신규인 경우), wiggle 진행-감쇠 채택 시 관련 토큰. 등록은 designer 단계에서 수행하며, planner spec은 토큰 목록·의미를 정의한다.
- [ ] 신규 색상 토큰은 도입하지 않는다(cozy 팔레트·기존 `headTongueColor`/`bulgeFill` 등 재사용). 신규 웹폰트 도입도 금지한다.
- [ ] 조정된 wiggle 토큰(`wiggleAmpFactor`, 변경 시 `wiggleFreqHz`)의 최종값이 game.js와 STYLE.md에서 일치한다.

## Non-functional Notes

### 페이로드 예산

- **전체 상한: ~75KB** (사용자 결정으로 본 버전부터 종전 ~50KB → ~75KB 상향). `docs/HARNESS.md:72` 문구를 동일하게 갱신한다(Set F).
- **현재 합계 약 51KB** (game.js 35,713B + index.html 4,249B + style.css 11,121B = 51,083B). 상향된 75KB 상한 대비 약 24KB 여유가 있어, 본 버전 모션 추가(예상 순증가 < 1.5KB: yawn ease 함수 + 직진 추적 + flick 게이팅 + 토큰 수개)는 예산에 충분히 수용된다.
- 그럼에도 vanilla·정적 3파일 원칙은 유지하며, 불필요한 코드 증가는 피한다. 빌드툴/미니파이 금지.
- 최종 합계가 75KB 미만임을 SCM/QA 단계에서 바이트 단위로 확인한다.

### 성능

- 모든 모션은 기존 RAF(`frame`/`draw`) 루프 내 산술 연산만 추가한다. 새 타이머·새 드로우콜·추가 캔버스 패스 없음.
- wiggle 절제는 토큰 값 변경(및 선택적 감쇠 계수 1곱)으로, 연산 비용 변화 없음.
- yawn은 직진 추적 상태 갱신(tick당 O(1)) + 머리 squash 합성(프레임당 O(1))만 추가한다. tongue flick은 기존 idle tongue 게이팅에 OR 조건 1개 추가로 비용 무시 가능.

### 정확성/논리 불변

- 본 버전 모션은 화면 렌더에만 관여하고 충돌·점수·food·bulge 인덱스·상태 전이·v0.5.8 보간 좌표를 변경하지 않는다(Set E).
- 직진 추적 상태는 **입력에 반응하는 읽기 전용 파생값**이며 게임 로직(입력 큐, 다음 tick 반영)에 영향을 주지 않는다.

### 모바일

- 모션 추가로 인한 입력 지연 없음. 입력은 종전대로 다음 tick에 반영.
- 작은 화면에서도 절제된 wiggle·미세 yawn 변형이 인접 셀을 침범하거나 보드를 벗어나지 않는다.

## Decisions

- **(A) wiggle은 절제하되 제거하지 않음** — 사용자 원문 의도("너무 많이 흔들려 조잡 → 눈에 띄게 줄이되 생동감은 남김")에 따라 `wiggleAmpFactor`를 0이 아닌 하향값으로 조정한다. 완전 제거는 v0.5.7 디지스천 생동감 목표를 훼손하므로 채택하지 않는다. 정확한 목표치는 토큰 조정 + designer 플레이 확인으로 확정한다.

- **(B) 토큰 조정 우선, 구조 변경 최소화** — wiggle 절제는 `drawBulges` 구조를 건드리지 않고 토큰 값 변경(및 선택적 감쇠 계수 1곱)만으로 달성한다. 회귀 위험·페이로드 증가를 최소화한다.

- **(C) idle tongue 재사용으로 flick 구현** — 머리에 이미 주기적 idle tongue와 `headTongue*` 토큰이 존재하므로, 신규 색·신규 그리기 경로 없이 게이팅에 OR 조건과(필요 시) 짧은 강조만 추가한다. 신규 색·폰트 도입 금지 제약을 자연히 충족한다.

- **(D) yawn은 squash 경로 재사용·미세·1회·쿨다운** — yawn은 머리 squash/스케일 변형을 재사용하여 별도 렌더 패스 없이 구현한다. 비반복·저빈도 원칙(연속 직진 N초 임계 + 쿨다운)으로 거슬리지 않게 한다. eat squash·pulse와의 합성 과장은 강도 절제와 designer 플레이 확인으로 방지한다.

- **(E) ambient 2종으로 범위 한정** — 사용자 의도가 "혀 낼름·하품 정도"이므로 본 버전은 tongue flick·yawn 2종만 추가하고 눈 깜빡임 등은 명시적으로 제외한다(향후 버전 후보).

- **(F) 직진 추적은 시간 기반 권장** — 스테이지마다 tick 속도가 다르므로(튜토리얼 느림, 상위 스테이지 빠름), tick 카운터 대신 시간 기반 임계를 권장하여 "체감 직진 시간"을 스테이지 무관하게 일정하게 유지한다. 최종 구현은 dev 결정.

- **(G) 페이로드 상한 75KB로 상향** — 사용자 결정으로 본 버전부터 페이로드 상한을 ~50KB → ~75KB로 상향한다. 현재 ~51KB로 여유가 크므로 본 버전 모션 추가가 예산에 안전하게 수용된다. HARNESS.md 문구를 동일하게 갱신한다.
