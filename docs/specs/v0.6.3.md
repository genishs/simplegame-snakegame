# v0.6.3 — 웹 페이지 제목을 "심플 스네이크"로 (Android versionCode 60301)

**Type:** Chore (이름 통일)
**Date:** 2026-10-03
**Milestone:** 0.6.3 (vc60301)

0.6.2에서 앱 런처 이름이 스토어 이름 "심플 스네이크"로 통일됐다(#29). 웹 페이지의 제목만 "뱀 게임"으로 남아 있어, 소유자 결정에 따라 웹도 "심플 스네이크"로 맞춘다.

## 범위

| 이슈 | 내용 | 웹 | 앱 |
|---|---|:-:|:-:|
| #38 | `index.html`의 `<title>`·`<h1>`을 "뱀 게임"에서 "심플 스네이크"로 | ✓ | ✓ |

- 웹은 `main` 병합 즉시 GitHub Pages에 반영된다.
- 안드로이드 0.6.2(versionCode 60202)가 Play 심사 중이므로 앱에는 다음 출시(versionName 0.6.3 / versionCode 60301) 때 들어간다. 웹 3파일은 빌드 때 앱 assets로 복사되므로 셸 변경은 없다.
- 범위 밖: `HISTORY.md`·`docs/specs`의 과거 기록(역사이므로 그대로), 본문 안내문의 "뱀"(캐릭터를 가리키는 말), 그 밖의 문구·레이아웃 변경.

## 동작 정의

- 브라우저 탭 제목(`<title>`)과 화면 제목(`<h1>`)이 "심플 스네이크"다.
- 제목이 4자에서 7자로 길어져도 한 줄이어야 한다. 보드 크기 계산(`--page-chrome-v`, `--portrait-chrome-v`)이 h1 한 줄 높이를 전제로 하기 때문이다.
  - h1은 `font-size: 28px; letter-spacing: 2px`(짧은 가로 화면은 20px, 1px)이고 글자 폭은 약 190px(가로 짧은 화면 약 133px)다. 컨테이너는 좌우 패딩 24px을 뺀 폭을 쓰므로 360px 폭 세로 화면에서 312px을 쓸 수 있어 줄바꿈되지 않는다. CSS는 바꾸지 않는다.
  - 폭이 약 240px보다 좁아지거나 글꼴 크기가 약 1.6배 이상 커지면 줄바꿈될 수 있다. 이번 범위에서는 막지 않는다.
- 버전: `GAME_VERSION` 0.6.3, `androidRev` 1(versionCode 60301).
